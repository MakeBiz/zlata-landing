# zlata-landing

Лендинг психолога Златы. Статический сайт (HTML/CSS/JS, без сборки).

## Структура

- `public/` — сам сайт (то, что отдаётся посетителю). Внутри `index.html` и страницы.
- `public/assets/data.js` — **единственный файл контента**: контакты, ссылки на соцсети, расписание, список статей. Правки текста и ссылок — здесь.
- `public/assets/styles.css`, `public/assets/site.js` — оформление и логика.

## Хостинг

Сайт разворачивается на **Timeweb Cloud → App Platform** из этого репозитория:

- Тип: **Frontend → HTML/CSS/JS**
- Ветка: `main`
- Команда сборки: пусто
- Каталог сборки: `public`

Автодеплой включён: любой коммит в `main` пересобирает сайт.

## Как обновляется

Правки вносятся в staging-папку на Маке и публикуются автопубликатором
(`.publish-request` → GitHub → Timeweb). Подробности — во внутренней инструкции проекта.
